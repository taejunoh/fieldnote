# 종목 대화 이동과 동시 작업 표시

사용자 요청: 종목 선택 시 최신 대화가 보이도록 하고, 여러 분석의 결과 완료를 웹에서 알아볼 수 있도록 한다.

- 최초 진입과 종목 전환의 해당 메시지 로드 완료 후 대화 영역만 맨 아래로 이동한다. 이전 메시지 불러오기나 주기적 조회가 과거 대화 열람을 강제로 끝내지 않게 한다.
- 소유자 전용 작업 개요 API는 각 종목의 최근 작업 ID·상태·시각만 반환한다. 전체 종목을 약 5초 간격으로 조회하여 탐색 목록에 진행·새 결과·실패를 표시한다.
- 새 완료 작업을 안내하고 클릭하면 해당 종목으로 이동한다. 실제 해당 대화 로드가 성공한 뒤 읽음 처리한다. 완료 읽음 표시는 계정과 기기별 localStorage에 보존한다. 브라우저 알림 권한과 이메일은 사용하지 않는다.
- 실패·사용량 대기·재로그인 필요는 성공 완료와 구분한다. 중복 요청·경합·종목 전환 시 오래된 응답이 선택된 종목이나 읽음 상태를 덮어쓰지 않게 한다.
- 검증: 종목별 상태와 읽음 판정·API 소유자 제한 테스트, TypeScript 및 린트, 실제 긴 대화의 최초/종목 전환 위치 확인. 검증용 모델 호출은 하지 않는다.

## 검증 결과

- 전체 Vitest: 20개 파일, 110개 테스트 통과. TypeScript 검사와 변경 파일 ESLint 통과.
- 배포 ID: 1c103494-e302-48af-bd2e-e4410e11deb1 (SUCCESS).
- 운영 overview API: 비로그인 401, 소유자 200, 7개 종목, 작업 메타데이터만 반환, no-store 확인. 격리 검증 세션만 종료했다.
- 실제 Chrome: 새로고침 후 MLB 최신 메시지 끝 위치 확인, NFL 전환 후 최신 메시지 끝 위치 확인, 축구 확인 필요 배지와 이동 안내 표시 확인.
- 모델 호출 또는 검증용 분석 작업을 실행하지 않았다. 다중 작업 완료·읽음 유지와 저장소 쓰기 실패 경합은 회귀 테스트로 검증했다.
