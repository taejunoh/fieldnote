# 종목별 최근 분석표

요청: 각 종목에서 최근 분석 결과의 실행표를 대화를 다시 읽지 않고 항상 확인한다.

- 각 종목의 **가장 최근 완료된 분석 작업**을 분석 완료 시각 기준으로 선정한다. 진행 중 작업은 전의 완료 결과를 유지한다.
- 현재 분석 7건 중 6건은 별도 추천 행 추출이 미완료다. 저장된 `recommendations`만 사용하면 대부분 빈 표가 되므로, 해당 분석 답변의 첫 유효한 Markdown 표를 그대로 표시한다. 첫 제목과 표 제목을 함께 표시하며 오래된 가져온 기록과 섞지 않는다.
- 표는 대화 제목과 스크롤 영역 사이에 고정한다. 컴팩트한 높이와 내부 스크롤을 사용해 채팅 입력 영역을 가리지 않는다. 스마트폰에서도 표시한다.
- 표는 모델의 당시 **분석 기록**이다. `BET` 판단이나 권장 유닛을 실제 베팅으로 처리하지 않는다. 답변에 표가 없으면 임의 내용을 만들지 않고 본문 확인을 안내한다.
- 결과 API는 인증된 소유자와 선택 종목으로 한정하고, 출처 링크를 포함한 표 Markdown과 작업 완료 시각만 반환한다. 원문 전체를 복제하지 않는다.
- 분석 완료·스포츠 전환·재접속 시 최신 표를 다시 불러온다. 표 조회 실패는 채팅을 막지 않는다.
- 검증: 유효한 표 판별, 최신 완료 작업 선정, 소유자 제한, 대화 로드 영향 없음, 데스크톱/모바일 레이아웃. 검증용 모델 호출 없음.
