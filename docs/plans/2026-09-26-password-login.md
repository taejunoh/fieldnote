# 개인 계정 비밀번호 로그인

사용자 승인: 기본 SMTP 발송 제한에 종속되지 않도록 이메일·비밀번호 로그인을 추가한다.

1. 기존 소유자 계정 UUID와 기록을 유지하며 Supabase signInWithPassword를 사용한다. 로그인 뒤 서버의 소유자 검증을 수행한다.
2. /auth/password는 인증된 소유자만 접근한다. 사용자가 새 비밀번호와 확인 값을 직접 입력하고 Supabase updateUser에 제출한다. 관리자 비밀번호 설정 엔드포인트는 만들지 않는다.
3. 최초 설정은 관리자 generate_link의 일회성 이메일 인증 토큰으로 기존 소유자 세션을 만든다. 콜백은 소유자 검증 후 고정 설정 경로로 이동한다. 인증 링크는 대화나 로그에 출력하지 않고 저장소 밖의 제한된 로컬 파일로 전달한 뒤 삭제한다.
4. 콜백 목적지·접근 제한·비밀번호 검증을 테스트하고 웹만 배포한다. 이메일 발송 없는 세션 검증으로 기존 기록 접근을 확인한다.
5. 사용자에게 비밀번호 입력 및 저장을 넘긴다. 실제 비밀번호 로그인 성공은 사용자 설정 이후 확인한다.

공개 회원가입과 유료 API 자동 전환은 활성화하지 않는다. 비밀번호 복구가 필요한 경우 인증된 개인 계정에 대한 별도 설정 절차가 필요하다.
